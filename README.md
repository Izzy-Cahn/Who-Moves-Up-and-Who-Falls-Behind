# Who Moves Up or Falls Behind?

Replication files for:

**Cahn, Yisroel and Esfandiar Maasoumi. _Who Moves Up or Falls Behind? Income, Wealth, and Heterogeneous Intergenerational Mobility._**

This repository contains the code, data documentation, cleaned analysis files, and results used in the paper. The analysis uses linked parent-child observations from the Panel Study of Income Dynamics (PSID) to study heterogeneity in intergenerational mobility. The main empirical approach estimates conditional probabilities of economically meaningful mobility events using parental income, wealth, and other family circumstances.

## Data

The data come from the [Panel Study of Income Dynamics (PSID)](https://psidonline.isr.umich.edu/default.aspx).

The analysis links individuals to their parental household heads using the longitudinal PSID family structure. Parental long-run income is constructed from available annual observations over 1985-1994, offspring long-run income from available biennial observations over 2009-2019, and family wealth is measured in 1989. Income measures are expressed in 2019 dollars. The primary analysis sample contains 2,707 linked parent-child observations.

The PSID custom extract used for the project is documented in `data/J359896_codebook.pdf`. To reconstruct the raw extract, download the variables listed in that codebook from the PSID Data Center and save the resulting file as:

```text
data/J359896.xlsx
```

### Cleaned analysis files

Running `code/psidcleaning.do` creates three analysis datasets:

- **`psidcleaned_data1.dta`** — relative rank mobility. `DV1-DV4` indicate upward movements of at least 10, 20, 30, and 40 percentile points; `DV5-DV8` define the corresponding downward movements.
- **`psidcleaned_data2.dta`** — absolute mobility relative to one's own parent. `I1-I4` indicate offspring income at least $5,000, $10,000, $15,000, and $20,000 above parental income; `I5-I8` define the corresponding downward movements.
- **`psidcleaned_data3.dta`** — mobility relative to the weighted median income of the parental generation. `A1-A4` indicate offspring income at least $5,000, $10,000, $15,000, and $20,000 above the parental-generation median; `A5-A8` define the corresponding downward outcomes.

The paper's main benchmark outcome is constructed in Python from `psidcleaned_data3.dta` and equals one when offspring long-run income is at least the PSID-weighted median of parental long-run income.

## Code

### `psidcleaning.do`

Stata code that constructs the linked parent-child sample and the cleaned analysis datasets. The script:

- imports the PSID custom extract;
- constructs individual and family identifiers;
- links offspring to parental household heads using the 1985-1994 PSID family structure;
- constructs long-run parental and offspring income;
- converts income measures to 2019 dollars;
- creates parental wealth, demographic, education, occupation, industry, family-structure, and geographic variables;
- constructs the alternative mobility outcomes; and
- saves the three cleaned `.dta` files described above.

### `WMU.py`

Main Python replication script. It reproduces the paper's principal machine-learning analysis and the alternative-mobility predictor-importance exercises.

Key features include:

- five-fold family-grouped cross-fitting using the PSID 1968 family identifier (`ID68`);
- three-fold weighted hyperparameter tuning within each outer training fold;
- Random Forest as the primary flexible prediction model;
- Gradient Boosting as an alternative prediction model;
- PSID sampling weights in model fitting and evaluation;
- training-fold-only missing-value imputation;
- family-cluster bootstrap uncertainty;
- nested information-set comparisons;
- calibration and realized-outcome validation;
- subgroup and socioeconomic heterogeneity analyses; and
- impurity, grouped permutation, and SHAP predictor-importance measures for alternative mobility definitions.

The random seed used in the Python analysis is `12345`.

### `WMU_additional_robustness.py`

Additional robustness and wealth analyses. This script is intended to be run after `WMU.py` and includes:

1. flexible linear and spline-logit benchmarks;
2. validation of broader family-background predictions while holding flexible income-only predictions approximately fixed;
3. common-support estimates for upward rank movements of 10, 20, 30, and 40 percentile points;
4. held-out permutation importance for parental income and wealth;
5. cluster-bootstrap uncertainty for changes in predictor importance; and
6. rank-standardized realized mobility comparisons across parental-wealth groups.

## Replication instructions

### Starting from the raw PSID extract

1. Download the custom PSID extract documented in `data/J359896_codebook.pdf`.
2. Save it as `data/J359896.xlsx`.
3. Update the paths in the scripts as described above.
4. Run the Stata cleaning file:

   ```stata
   do code/psidcleaning.do
   ```

   This creates:

   ```text
   data/psidcleaned_data1.dta
   data/psidcleaned_data2.dta
   data/psidcleaned_data3.dta
   ```

5. Run the main Python analysis:

   ```bash
   python code/WMU.py
   ```

6. Run the additional robustness analysis:

   ```bash
   python code/WMU_additional_robustness.py
   ```

7. Generated tables, numerical results, and figures are written to `results/`.

### Starting from the cleaned data

If the three cleaned `.dta` files are already available in `data/`, begin with Step 3 above and then run the two Python scripts.

## Reproducibility notes

All main predicted probabilities are constructed out of sample. Observations sharing the same original PSID family identifier are kept in the same cross-fitting fold, preventing members of the same family from appearing in both the training and held-out samples. Hyperparameters and preprocessing steps are estimated using training data only. PSID sampling weights are used throughout the main prediction and evaluation exercises.

The common-support analysis restricts the sample to offspring whose parents begin at or below the 60th percentile of the parental-income distribution. This ensures that every observation is mechanically capable of upward movements of 10, 20, 30, and 40 percentile points, allowing predictor importance to be compared across thresholds on a common sample.
